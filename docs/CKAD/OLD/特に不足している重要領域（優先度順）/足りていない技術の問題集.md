## 問題 2　★ NetworkPolicy

> **Namespace**：`secure`  
> **所要目安**：8 分

`secure` Namespace には以下 2 Deployment が稼働中（変更禁止）。

|名前|ラベル|ポート|
|---|---|---|
|`frontend`|`app=front`|8080/TCP|
|`backend`|`app=back`|9090/TCP|

要件：

- **NetworkPolicy** `allow-front-to-back` を作成し、  
    `frontend` Pod からのみ `backend` Pod:9090 への通信を許可。
    
- それ以外の Ingress はすべて拒否（デフォルト deny）。
    

> **保存** `/opt/exam/np-front-back.yaml`

### 問1 StorageClass

```yaml
# /opt/exam/sc-fast-local.yaml
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: fast-local
provisioner: kubernetes.io/no-provisioner
volumeBindingMode: WaitForFirstConsumer
reclaimPolicy: Delete
---
# /opt/exam/planet-volume.yaml
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: planet-data-pvc
  namespace: planet
spec:
  accessModes: ["ReadWriteOnce"]
  resources:
    requests:
      storage: 500Mi
  storageClassName: fast-local
---
apiVersion: v1
kind: Pod
metadata:
  name: planet-pod
  namespace: planet
spec:
  volumes:
    - name: data
      persistentVolumeClaim:
        claimName: planet-data-pvc
  containers:
    - name: alpine
      image: alpine
      command: ["sleep","3600"]
      volumeMounts:
        - name: data
          mountPath: /data
```

    - from:

      ports:
        - protocol: TCP

### 問5 Rollout

```bash
# hist-rollback.sh
kubectl -n history set image deploy/hist-app \
  hist-app=nginx:1.25-alpine

kubectl -n history rollout status deploy/hist-app

kubectl -n history rollout history deploy/hist-app

kubectl -n history rollout undo deploy/hist-app --to-revision=1
```
