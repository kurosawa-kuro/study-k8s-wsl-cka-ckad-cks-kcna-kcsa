## 🎯 ハンズオン課題一覧（領域別）

### 🔸【領域1】ConfigMap・Secret（環境変数・マウント）

**ハンズオン課題：**

- ConfigMapを作成し、Podに環境変数として注入。
    
- ConfigMapをPod内にVolumeとしてマウントする方法を確認。
    
- Secretを作成し、Podの環境変数およびマウントで使用する。
    
- Podから環境変数とVolume経由で正しく値が取得できることを確認。
    

**例（CLI演習コマンド）:**

```sh
# ConfigMap作成
kubectl create configmap app-config --from-literal=APP_MODE=production --dry-run=client -o yaml > app-config.yaml
kubectl apply -f app-config.yaml

# Secret作成
kubectl create secret generic app-secret --from-literal=PASSWORD=secret123 --dry-run=client -o yaml > app-secret.yaml
kubectl apply -f app-secret.yaml
```

---

### 🔸【領域2】PersistentVolume・PVC・StatefulSetの完全理解

**ハンズオン課題：**

- PersistentVolume（PV）を定義し、PersistentVolumeClaim（PVC）を作成。
    
- PVCをPodにマウントして、データ永続性を確認（データがPod再作成後に維持されることを確認）。
    
- StatefulSetを作成し、Pod名・ストレージが永続的に管理されることを確認。
    

**例（YAML）:**

```yaml
apiVersion: v1
kind: PersistentVolume
metadata:
  name: pv-sample
spec:
  capacity:
    storage: 1Gi
  accessModes:
    - ReadWriteOnce
  hostPath:
    path: /mnt/data

---
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: pvc-sample
spec:
  resources:
    requests:
      storage: 1Gi
  accessModes:
    - ReadWriteOnce
```

**StatefulSet確認コマンド:**

```sh
kubectl apply -f statefulset-sample.yaml
kubectl get statefulset,pods,pvc -o wide
```

---

### 🔸【領域3】Job・CronJob・DaemonSetの理解と実践

**ハンズオン課題：**

- Jobを作成し、正常終了後の挙動を確認。
    
- CronJobを設定し、毎分実行されることを確認（ログやPodの生成を追跡）。
    
- DaemonSetを作成し、すべてのノードで必ず1Pod稼働することを確認。
    

**Jobの例:**

```yaml
apiVersion: batch/v1
kind: Job
metadata:
  name: simple-job
spec:
  template:
    spec:
      containers:
      - name: job-container
        image: busybox
        command: ["echo", "Job Completed"]
      restartPolicy: Never
```

**CronJobの例:**

```yaml
apiVersion: batch/v1
kind: CronJob
metadata:
  name: cronjob-sample
spec:
  schedule: "*/1 * * * *"
  jobTemplate:
    spec:
      template:
        spec:
          containers:
          - name: cron-container
            image: busybox
            command: ["echo", "Hello from cronjob"]
          restartPolicy: OnFailure
```

**DaemonSetの例:**

```yaml
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: daemonset-sample
spec:
  selector:
    matchLabels:
      name: daemonset-sample
  template:
    metadata:
      labels:
        name: daemonset-sample
    spec:
      containers:
      - name: daemon-container
        image: busybox
        command: ["sleep", "3600"]
```
