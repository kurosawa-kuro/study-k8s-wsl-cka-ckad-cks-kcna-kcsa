#### どう組み込むか？ 参考ルート

1. **KCNA-JP → KCSA**（概念・セキュリティ軸）で “用語の壁” を破壊
2. **PCA → OTCA** で監視 / トレーシングの横串スキルを確保
3. **Terraform Associate** で IaC を公式に固める
4. **SnowPro Core** ＋ **AWS Data Engineer**（または **Databricks**）で DWH / ETL を標準フレームで整理
5. その後 **CKA-JP → CKAD-JP → CKS-JP** をハンズオン連打で取得

こう配置すると、各ハンズオン試験で「なぜこの設定が必要か？」を**座学側で先取り**できるため、実務・学習ともにムダがありません。興味のあるものからピックアップしてロードマップに追加してみてください！
