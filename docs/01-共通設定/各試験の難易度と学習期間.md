#### キーポイント

* **費用差**

  * 2025 年2 月の値上げ以降、ハンズオン型（CKA/CKAD/CKS）は一律 **\$445**([training.linuxfoundation.org][8])。
  * アソシエイト級（KCNA/KCSA）は **\$250–275** と比較的安価。

* **形式の違い**

  * CKA/CKAD/CKS は本番クラスタを SSH で操作する “コーディング系（Performance-Based）”。コマンド入力速度と YAML テンプレの持ち込みが合否を左右。
  * KCNA/KCSA は 4-択前後の **クイズ形式**。範囲は広いがタイピング負荷は少ない。

* **日本語対応**

  * CKA/CKAD/CKS/KCNA は公式に日本語タスク提供。監督官は英語。
  * KCSA は UI ロケール切替こそあるものの、タスク全文の日本語版はまだアナウンスなし（2025 年6 月時点）。

* **受験順序の判断材料**

  1. **業務ロール**: SRE/Ops 寄り ➜ CKA 先行、Dev 寄り ➜ CKAD 先行も可。
  2. **セキュリティ志向**: 基礎を固めたら KCSA→CKS で段階的に深掘り。
  3. **学習コスト**: ハンズオン試験はラボ環境と模試（Killer.sh 等）を用意し、実戦時間管理を必ず練習。

これらを踏まえ、まずは **KCNA + お好みの学習プログラム（Udemy/KodeKloud など）** で基礎を固め、次に CKA or KCSA へ進むと、負荷と費用のバランスが取りやすいです。
